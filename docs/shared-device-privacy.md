# 共用端末プライバシー方針（Stabilization）

## 実装した保護

- 「この端末の履歴を消す」操作で、相談履歴、送信待ち、入力途中の下書きをまとめて削除する。
- 送信待ちデータは24時間を超えると自動的に破棄する。
- 入力途中の下書きは24時間で復元対象外にする。
- 確認URLはサーバー側では30日で失効し、端末履歴は7日で整理する。
- 原文はサーバーに保存するが、住民画面には内部メモやSafety判定を表示しない。

## 利用者への案内

共用端末では、相談終了後にステータス画面の「この端末の履歴を消す」を押す。確認URLをコピーした場合はクリップボードとブラウザ履歴に残る可能性があるため、端末を次の人へ渡す前に消去する。

## 未解決リスク

- `localStorage` の内容はブラウザ拡張・端末管理者・同一端末の別アプリから保護されない。
- Bearer形式の確認URLを知る人はログインなしで状態を確認できる。画面共有・スクリーンショット・アクセスログの運用が必要。
- 端末のOSバックアップ、ブラウザ履歴、入力支援機能のログまではアプリから消せない。
- オフライン送信待ちの原文は端末内に残る。紛失時の遠隔削除はできない。

## Gate判断

「共用端末でも安全」とは判定しない。削除導線とTTLは改善したが、自治体運用に入れる前に、端末貸出手順、ブラウザプロファイルの初期化、確認URLの配布方法、保存期間を実務者と決める必要がある。
