# Pilot Plan

## 目的

PilotはKikumaeの効果を証明する試験ではない。A〜D比較のUI、ケース、Ground Truth、タイマー、質問文、データ保存、疲労、操作ミス、精神的負担1〜5尺度を発見するための方法検証である。職員のストレス軽減を結論づけない。

## 対象

- 学生、教員、一般成人12〜20名。
- 避難所業務の専門家の結果と混ぜない。
- 視覚・入力・言語面での支援が必要な参加者を排除せず、支援方法を記録する。

## 実施

1. 同意、匿名ID、背景質問。
2. 練習2件。
3. 30ケースをカウンターバランスして提示。1人が同じ基礎ケースを別条件で見ない。
4. ケースごとに総合精神的負担、読む負担、対応負担、把握時間、正答、Safety、原文閲覧、信頼感を記録。
5. 終了後に自由回答で「何が分かりにくかったか」を聞く。

## Pilot成功条件

- 手順完了率90%以上。
- タイマー・条件・Ground Truthの欠損/操作不能5%未満。
- 重大Safety見逃し0件。
- 同じ設問を参加者が概ね同じ意味で解釈できる。
- 4条件の表示差が、内容ではなく装飾やAIラベルによるものになっていない。

## Pilot停止条件

- 重大Safetyの見逃し。
- 原文とカードの意味不一致を参加者が高頻度で指摘。
- 参加者に疲労・不安・苦痛が生じる。
- データ保存、匿名化、条件割付に不備。
- Ground Truthのレビュー不一致が解消できない。

## Pilot後の修正

ケース、設問、タイマー、割付の修正は、実務者評価の前に版を凍結し、変更履歴を残す。Pilot結果でSuccess Criteriaを良く見せるための閾値変更はしない。

## 禁止する主張

Pilotのみから、職員の負担・ストレスが何%減った、現場で使える、安全である、AIが必要であるとは言わない。Pilotでは尺度と実験設計の妥当性だけを判定する。
