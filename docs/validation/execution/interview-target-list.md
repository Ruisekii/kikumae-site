# Interview Target List

## 目的

同じ職種だけに聞いて確認バイアスを作らない。相談を受ける人、判断する人、引き継ぐ人、支援する人を分ける。

## 優先順位

| 優先 | 候補 | 確認したいこと | 目標 |
| --- | --- | --- | ---: |
| 1 | 自治体防災担当 | 窓口、指揮系統、既存基盤、調達・責任 | 2〜3 |
| 1 | 避難所運営経験者 | 実際の受付、優先順位、引継ぎ | 2〜3 |
| 1 | 避難所運営委員/施設管理者 | 現場制約、端末・紙・人員 | 1〜2 |
| 2 | 保健師/DHEAT/福祉担当 | 体調・要配慮者・Safety情報 | 1〜2 |
| 2 | 社協/外国人支援/ボランティア | 非デジタル、外国語、支援者入力 | 1〜2 |
| 3 | 学校の防災担当 | 施設運用、訓練、教員の引継ぎ | 1〜2 |
| 3 | 教員等の予備候補 | 問いの分かりやすさ、別視点 | 0〜2 |

## 3〜5人の最初の探索

最初は次の異なる立場を優先する。

1. 自治体または防災担当
2. 避難所運営経験者
3. 施設管理者または運営委員
4. 保健・福祉または支援者
5. 学校/教員等の予備候補

3〜5人終了時点では結論を確定せず、質問・分類・反証を見直す。

## 5〜10人の実務者段階

役割の異なる5〜10人で、以下の違いを比較する。

- 相談を最初に受けるか、後から判断するか
- 訓練経験のみか、実災害経験があるか
- デジタル記録があるか、紙・口頭中心か
- 医療/福祉案件を扱うか
- 避難所単位か本部単位か

## 除外・注意

- Kikumae開発者だけでProblemを確認しない。
- 製品導入を決める権限のない人の肯定だけで需要を証明しない。
- 実在住民の個人情報や未公開の被災詳細を収集しない。
- 謝礼や協力関係が回答を誘導しないよう記録する。
