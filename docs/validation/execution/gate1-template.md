# Gate 1 — Problem Validation Template

## 判定対象

「相談の把握、情報不足、優先順位、記録、引継ぎの問題が、実務上の重要な問題として存在するか」を判定する。Kikumaeへの期待やConcept Testの感想は主証拠にしない。

## 入力

- Interview人数:
- 役割の種類:
- 組織の種類:
- 具体的な出来事の数:
- Problem existsの件数:
- Low priorityの件数:
- Not foundの件数:
- Different Problem Foundの件数:
- Frequency分布:
- Severity分布:
- Workaround quality分布:
- Unmet need分布:

| 問題 | 役割 | 具体例 | 頻度 | 影響 | 現行workaround | 誰が困るか | 反証 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

## 判定

- [ ] Problem exists: 複数の実務者から具体的な問題が確認された
- [ ] Problem exists but low priority
- [ ] Problem not found
- [ ] Different problem found

### Decision

- PASS
- REFINE
- FAIL / PIVOT
- STOP

## 判定理由

ここに、肯定例だけでなく反証、現行で十分な例、別問題を記録する。
