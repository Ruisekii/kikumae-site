# Interview Request Message

## メール・メッセージ本文

件名：避難所運営の相談受付についての短いヒアリングのお願い

〇〇様

突然のご連絡失礼いたします。

現在、避難所で住民から出る困りごとや要望が、実際にどのように受付・記録・共有されているのかを調べています。

システムの導入提案や営業が目的ではありません。実際の避難所運営、訓練、または関連業務で、情報がどのように届き、誰が対応し、どこで困るのかを教えていただきたいと考えています。

15分程度のオンラインまたは対面で、以下のような点を伺えれば幸いです。

- 住民からの相談・要望が届く経路
- 記録・優先順位・引継ぎの方法
- 情報不足や対応漏れが起きる場面
- 通信断、端末不足、非デジタル利用者への対応

実在する住民の氏名や個人情報、詳細な被災情報は伺いません。回答は研究・試作の検証にのみ使用し、製品導入や効果を前提にした質問は行いません。

ご都合がよろしければ、候補日時をいくつかお知らせいただけますでしょうか。

どうぞよろしくお願いいたします。

## 口頭での短縮版

「避難所で住民の困りごとがどう受付・記録・引継ぎされるかを理解するための調査です。営業ではありません。15分ほど、実際の運用で困る場面を教えていただけませんか。」
