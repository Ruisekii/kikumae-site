# A〜D Pilot Execution Sheet

## 目的

Pilotは効果証明ではなく、評価設計のデバッグである。A〜Dが公平に提示され、Ground Truth・タイマー・質問・保存が機能するかを確認する。

## 実施前チェック

- [ ] 30基礎ケースからPilot用20〜30件を固定した
- [ ] 各ケースのGround Truthを人間2名がレビューした
- [ ] A〜Dの条件順をカウンターバランスした
- [ ] 同じ基礎ケースが同一参加者に複数条件で出ない
- [ ] Cのプロンプト・モデル・生成設定を固定した
- [ ] Bが十分に使えるフォームである
- [ ] Dだけが有利になる特別な説明・色・導線がない
- [ ] Safetyケースの停止・確認手順を用意した
- [ ] データに実在住民の情報が含まれていない
