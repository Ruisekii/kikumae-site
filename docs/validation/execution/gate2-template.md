# Gate 2 — Pilot Validity Template

## 判定対象

A〜D比較Pilotが、効果を主張する前提として妥当な設計になっているかを判定する。Pilot結果からKikumaeが勝ったとは結論しない。

## 必須確認

- [ ] 20〜30ケースを使用した
- [ ] 重要事実、要望、場所、人数、Safety、不確実性、訂正のGround Truthが人間2名で確認された
- [ ] AI出力をGround Truthにしていない
- [ ] Bが合理的なフォーム＋ルールである
- [ ] Cが通常利用を想定した十分なBaselineである
- [ ] Dだけが有利な表示・説明になっていない
- [ ] 同一参加者に同じ基礎ケースを複数条件で見せていない
- [ ] 条件順をランダム化/カウンターバランスした
- [ ] タイマーと完了定義が明確だった
- [ ] 参加者が設問を理解した
- [ ] 欠損/操作不能5%未満
- [ ] 重大Safety見逃し0
- [ ] 参加者の疲労・苦痛・個人情報問題がなかった

## 判定

- PASS: Practitioner Evaluationへ進める
- REFINE: ケース/設問/条件を修正して再Pilot
- FAIL: 設計を作り直す。効果の結論は禁止
