# Pilot Case Set

## 使用方法

Pilotでは、既存の `docs/validation/abcd-case-design.md` の基礎ケースとGround Truthを正本として使用する。最初のPilotは、以下の24ケースを推奨する。各ケースに4バリアントを用意し、同一参加者へ同一基礎ケースを複数条件で提示しない。

## 追加言語ケース

最初の24件に加え、可能なら以下を2件追加する。

- C26: `孩子39度，没精神。`
- C28: `물이 없고 세 명입니다。`

追加時も、翻訳の正しさと相談整理の正しさを混同しない。原文を正本として表示する。

## バリアント

各ケースについて、以下の4形式を作る。

1. 丁寧な文章
2. 口語・短文
3. 感情を含む文章
4. 誤字、省略、訂正、伝聞のいずれかを含む文章

バリアントで人数、Safety、否定、不確実性、場所、時刻を変更しない。
