# Problem Interview 5分版

## 目的

短時間で、相談の把握・記録・引継ぎに具体的な問題が存在する可能性を確認する。効果や製品評価は行わない。

## 進行台本

### 冒頭（30秒）

「避難所や災害時の相談受付・情報共有の実態を知るために、5分だけお話を伺います。製品の営業ではありません。最近の具体的な出来事を教えてください。」

### 質問（約4分）

1. **避難所運営の中で、精神的に最も負担が大きい業務は何ですか？**
2. **その負担について、最近または訓練で具体的にはどんなことがありましたか？**
3. **避難所で住民から困りごとや要望が出た場合、通常どのような流れで対応されますか？**
4. **その内容は、誰がどこへ記録し、他の職員へどう伝えますか？**
5. **相談の把握・情報不足・引継ぎが問題になった具体例はありますか？**

### 深掘り（30秒）

「それは最後にいつ起きましたか？誰が対応し、どう記録しましたか？」

## 記録するもの

- 具体例があったか
- Problem分類: Problem exists / Low priority / Not found / Different problem
- 頻度、影響、現在の workaround
- 参加者が自発的に「相談」「情報不足」「引継ぎ」「感情的な対応」を挙げたか

Kikumae、AI、感情分離、LLMという言葉はこの版では出さない。
