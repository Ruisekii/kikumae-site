# A〜D Case Design

## 方針

すべて匿名合成ケースを用いる。実在住民・実災害の個人情報は使わない。30基礎ケースを各4バリアントへ展開し、同じ内容を別条件で同一参加者へ見せない。

Ground Truthは、相談文からAIが出力したものではなく、ケース作成時に人間が先に固定する。

## バリアント設計

各基礎ケースに以下の4形式を作る。

1. 丁寧な表現
2. 口語・短文
3. 感情を含む表現
4. 誤字・省略・訂正を含む表現

意味を変えるバリアントを作らない。Safetyの有無、否定、不確実性、人数、場所、時刻、最新訂正は人間レビュアー2名が確認する。

## 難易度の均衡

- Safety: 6件以上、否定/境界: 4件以上、非Safetyの強い感情: 3件以上。
- 物資/設備: 10件以上、医療/安全: 8件以上、情報不足/訂正: 6件以上。
- 日本語以外: 6件以上。言語差を製品効果と混同しない。
- 単純・複合・不確実・長文を各条件へ均等割付する。
