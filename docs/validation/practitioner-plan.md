# Practitioner Evaluation Plan

## 目的

自治体・避難所の実務者が、A〜Dのどの条件で、重要情報を失わず、住民対応による精神的負担を減らし、実際の引継ぎを安全に行えるかを確認する。Problem Interviewとは別セッションとして実施する。

## 対象

目標12〜24名。

- 自治体防災担当
- 避難所運営経験者
- 施設管理者・運営委員
- 保健師/DHEAT・福祉支援
- 外国人・要配慮者支援

役割、経験年数、デジタル習熟、最近の訓練経験を記録し、学生Pilotと分けて分析する。

## セッション

### 事前

- 研究目的、匿名化、停止権、Safety上の限界を説明。
- Kikumaeの名称、AI優位性、期待効果を先に説明しない。
- 30ケース、A〜D割付、Ground Truth、正答キー、停止手順を固定。

### タスク

各ケースで、相談を読み、対応に必要な情報を記録し、次の担当・対応を選ぶ。完了時間、重要情報、Safety、原文閲覧、信頼感、負担、操作ミスを記録する。

### 事後インタビュー

- 既存の業務に置くなら誰が使うか。
- どの情報はカードで足りず原文が必要か。
- どの誤りが危険か。
- 紙・口頭・巡回・既存システムとどう併用するか。
- Dに追加された複雑さに価値があるか。
- AIが不要な部分はどこか。
- 運用責任、保持期間、障害対応を誰が担うか。

## 分析

- Primary KPI: 重要情報の把握精度を許容範囲内に保った、総合的な精神的負担1〜5。
- Guardrail: 重要事実、Safety、原文消失、Evidence、否定、不確実性、訂正、対応判断。
- Secondary: 読む負担、対応する負担、把握時間、引継ぎ判断、読みやすさ、信頼感1〜5、原文閲覧率、継続意向。
- 条件順、役割、ケース難易度を層別する。
- 平均だけでなく中央値、個別の失敗、誤読の理由を報告する。

## 成功条件（暫定）

- Dの総合精神的負担中央値がAより1.0ポイント以上低い。
- DがB/Cに対して少なくとも1つの明確な業務上の価値を示す。
- Dの重要事実正答率が最良対照から3ポイント超下回らない。
- Critical Safety false negative 0、意図/不確実性/対応判断の重大誤り0、原文消失0。
- 70%以上が既存業務の引継ぎに使えると評価し、80%以上が中核タスクを完了。

## 失敗・停止条件

- 重大Safety見逃し。
- 精神的負担がAとほぼ変わらない。
- DがBより負担・正答・速度・導入容易性で劣る。
- DがCと同等で、原文保持・状態管理・Evidenceが追加コストを正当化しない。
- 原文閲覧率が極端に高く、整理カードだけで把握できない。
- 参加者が現場の主要問題を文章整理ではなく、物資・人員・権限・担当不明と判断する。
- 個人情報、同意、評価データ保存に不備。

## 結論の扱い

主観的負担だけで成功とはしない。重要情報、Safety、意図、不確実性、対応判断をGuardrailとして同時に確認する。効果がない場合はB相当のフォーム＋原文保存＋Safety＋職員カード＋Exportへ縮小する。AIを残すこと自体は成功条件ではない。
