# Kikumae Goal Tree

## 最上位Purpose

**避難所職員の精神的ストレスを軽減する。**

これは最終目的であり、AI・整理カード・フォーム・翻訳は手段である。下位のOutcomeは、外部調査や実務者評価で支持されるまで仮説として扱う。

```text
避難所職員の精神的ストレス軽減
│
├─ A. 強い感情への直接曝露を減らす（仮説）
│  ├─ 刺激の強い原文を毎回直接読まなくても初期把握できる
│  ├─ 感情の存在を消さず、事実と分けて段階表示する
│  ├─ 必要な場合だけ原文を確認できる
│  └─ 測定: 総合精神的負担、読解負担、原文閲覧率、閲覧理由
│
├─ B. 情報把握の不確実性を下げる（仮説）
│  ├─ 場所・人数・時刻・症状・要望・経緯を把握しやすくする
│  ├─ 不明、伝聞、可能性、訂正を確定値にしない
│  ├─ 根拠を原文/本人入力へ遡れるようにする
│  └─ Guardrail: 重要情報正答率、意図/不確実性保持、Evidence
│
├─ C. 引継ぎ時の心理・認知負荷を下げる（仮説）
│  ├─ 担当・状態・次のActionを一目で確認する
│  ├─ 同じ相談を繰り返し読み直さない
│  ├─ 公開コメントと内部メモを分ける
│  └─ 測定: 対応判断負担、引継ぎ時間、対応判断精度
│
├─ D. 外国語・入力困難による理解負担を下げる（仮説）
│  ├─ 原文を保持したまま翻訳/支援入力を補助する
│  ├─ 高齢者・障害者・スマホ非利用者を排除しない
│  ├─ 紙・口頭・巡回からの情報も登録できる
│  └─ 測定: 意味保存、到達率、支援者の入力負担
│
└─ E. 住民が声の到達と進捗を確認できる（仮説）
   ├─ 受付済み・確認中・対応中・解決を確認できる
   ├─ 内部情報を漏らさず公開可能な進捗を返す
   └─ 測定: 受付確認率、進捗確認率、誤解、安心感
```

## Safetyと原文の不変条件

```text
Stress Reduction
        WITHOUT
Voice Loss
```

目的のために原文を隠すことは許されるが、削除・改変・根拠のない断定は許されない。以下はGoal Treeの全枝に共通するGuardrailである。

- 原文の消失・改変0。
- 重要情報の欠落を実用上許容できる範囲に収める。
- Safety false negative 0を目標とする。
- 不確実性、否定、伝聞、最新訂正を保持する。
- AI整理を正本にしない。
- 重要な判断・返信・完了は職員確認を必要とする。

## 検証順序

```text
1. 職員の精神的ストレスが住民対応と関係するか
       ↓
2. その負担が現場の優先課題か
       ↓
3. A〜D/Eのどの手段が負担を減らすか
       ↓
4. 情報精度・Safety・意図保持が壊れていないか
       ↓
5. 実務者評価とControlled Drillへ進むか
```

## 未支持のOutcome

以下は有望な仮説だが、現時点で事実として扱わない。

- 感情と事実の分離が職員の精神的負担を下げる。
- 原文閲覧率低下が負担軽減を意味する。
- 外国語整理が職員負担を下げる。
- 住民が進捗を見られることで安心する。
- Kikumaeがフォームや単純LLMより優れる。

## Feature Filter

新機能は必ず次の問いに答える。

> この機能は、どの職員のストレス要因を、どの測定可能な経路で減らすのか？

答えられない機能は **NOT NOW**。AIの新モデル、mmWave、複数避難所、在庫画像認識などは、現場評価で必要性が確認されるまでGoal Treeの外に置く。
