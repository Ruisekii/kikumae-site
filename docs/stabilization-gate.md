# Stabilization Gate

作成日: 2026-09-09

このGateではPhase 3C以降の機能開発・公開更新を停止する。合格していない項目を「実装済み」「本番対応」と表現しない。

| Gate | 判定 | 根拠 |
| --- | --- | --- |
| 原文不変性 | **コード契約通過、実機統合は未達** | `stabilization-contract-evaluation.json`。本番相当D1の追記・復旧試験は未実施 |
| サーバー正本Incident | **コード契約通過、運用Gate未達** | ブラウザIncidentを無視しサーバー再構築。ただし本番認証・DB統合試験は未実施 |

## 判定

- 公開版更新: **HOLD**
- 本番データへの変更: **HOLD**
- 人間評価（限定された匿名・合成データの原型評価）: **GO（安全主張なし）**
- 自治体ヒアリング: **GO（研究・要件確認のみ）**
- 防災訓練: **HOLD**。まず机上・開発環境の限定試験に留める
- 新機能開発: **HOLD**
- 複数避難所対応: **HOLD**

## 停止条件

コードは新機能のためには増やさない。次に変更してよいのは、(1) 原文・Safety・認証・復旧を壊す不具合、(2) Gateの検証に必要な最小テスト、(3) ヒアリングで確認した明確な業務阻害、のみに限定する。
