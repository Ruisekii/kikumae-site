# きくまえ運用メモ

## データの保存とバックアップ

きくまえのFAQ・質問・回答・監査ログは、Workerの一時メモリではなく、Sitesに接続したD1データベースへ保存されます。デプロイやコード変更だけではデータは消えません。

本番データのバックアップは、Sitesのプロジェクト設定に表示されるD1データベースを対象に、管理者だけが実行します。バックアップファイルには匿名質問の原文や回答が含まれる可能性があるため、リポジトリへ保存せず、暗号化した保管先へ保存してください。

推奨運用：

1. 変更前にD1のスナップショットまたはSQLエクスポートを取得する。
2. エクスポートの取得日時・対象環境・スキーマバージョンを記録する。
3. 本番とは別の安全な環境へ復元できることを四半期ごとに確認する。
4. 復元確認後も、保持期限とアクセス権を見直す。

SitesのD1バックアップ機能を使えない環境では、Sitesの管理画面またはプロジェクトに紐づくWrangler設定から対象データベースを確認してエクスポートします。データベースIDやトークンは環境変数・Secretsで扱い、ログやコミットへ出力しません。

## 認証情報

- 窓口管理者パスワードはPBKDF2-SHA-256（Workersランタイムで利用できない場合のみ既存の強化HMACへフォールバック）でハッシュ化されます。
- 運営者のChatGPTユーザーIDは`KIKUMAE_OWNER_USER_ID` Secretで照合します。フロントエンドへ埋め込みません。
- セッションはサーバー側で失効でき、ログアウト時に削除されます。

## 個人情報と監査

質問者には氏名・住所・電話番号・メールアドレス・学籍番号・社員番号などを書かないよう案内します。入力に個人情報らしい文字列やURLが含まれる回答・FAQは、公開前にサーバー側でブロックします。管理者のFAQ操作、質問への回答、FAQ候補の処理は監査ログへ記録されます。

監査ログは原因調査のために必要な最小限の識別子と操作時刻だけを保存します。窓口を削除すると、その窓口に属するFAQ・質問・候補・セッション・監査ログも同じD1トランザクションで削除されます。
