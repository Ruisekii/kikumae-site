# Kikumae Stress Reduction Hypothesis

## 目的

Kikumaeの最終目的を、**避難所職員の精神的ストレス軽減**として明示する。ただし、これは現在確認済みの効果ではなく、検証対象の仮説である。

## Core Problem Hypothesis

避難所職員は、被災者からの怒り・焦り・不安・要求・強い不満などを直接繰り返し受け止めることで精神的負荷を受ける可能性がある。

### まだ分かっていないこと

- 住民対応が職員の精神的負担の上位要因か。
- 強い感情を含む相談の頻度。
- 原文を読むことと、対応判断そのもののどちらが負担か。
- 職員が実際に原文を避けたいと感じているか。
- 問題の中心が、感情ではなく人員・物資・権限・引継ぎではないか。

## Solution Hypothesis

住民の原文を保持しながら、事実・要望・経緯・感情・Safety・不確実性を段階的に提示することで、重要情報の把握精度と対応判断を維持しつつ、職員の精神的負担を減らせる可能性がある。

## 仮説の構造

```text
強い感情を含む相談への直接曝露
        ↓ 可能性のある負担要因
精神的ストレス・認知負荷
        ↓ 解決仮説
原文保持 + 段階表示 + 根拠 + Safety + 人間確認
        ↓ 測定対象
精神的負担低下
        ↓ 必須条件
重要情報・意図・不確実性・Safetyを失わない
```

## 目的と手段

### Purpose

- 職員の精神的ストレス軽減。

### Outcomes / Mechanisms

- 刺激の強い原文を毎回直接読まなくて済む。
- 感情と事実を分けて受け止められる。
- 必要な経緯・不確実性を保ったまま情報を把握できる。
- 引継ぎ時の心理・認知負荷が下がる。
- 外国語・入力困難による理解負担が下がる。

### Guardrails

- 原文を失わない。
- 重要情報を欠落させない。
- 原文にない情報を追加しない。
- Safetyを見逃さない。
- 不確実性を断定へ変えない。
- AI整理を正本にしない。
- Human-in-the-loopを維持する。

## 測定

### Primary

重要情報の把握精度を実用上許容できる範囲に維持した、相談1件あたりの総合精神的負担1〜5。

### Secondary

- 読むこと自体の負担
- 対応することへの心理的負担
- 内容把握時間
- 対応判断時間
- 原文閲覧率と閲覧理由
- 認知負荷、読みやすさ、信頼感
- 対応判断精度

### 最低限の比較

- A: 原文のみ
- B: 構造化フォーム＋ルール
- C: 単純LLM要約
- D: Kikumae
- E: Structured-first Hybrid（第二段階）

## Successの仮条件

- Dの総合精神的負担中央値がAより1.0ポイント以上低い。
- 重要情報正答率が95%以上、または最良条件から3ポイント超低下しない。
- Safety false negative 0。
- 意図、不確実性、否定、最新訂正、経緯を失わない。
- BまたはCに対して少なくとも1つ明確な業務上の価値がある。

## 反証・Failure

- 住民対応ストレスが主要課題として出ない。
- Dの精神的負担がAとほぼ同じ。
- 負担は下がるが重要情報やSafetyを失う。
- CとDが同等で、Dの複雑さが不要。
- Bが精神的負担・正答率・速度・導入容易性のすべてで優れる。
- 原文閲覧率が下がるだけで、判断精度も下がる。

## PIVOT

精神的ストレスは存在するが、AI Organizerが解決しない場合は、以下へ変更する。

- AI Organizer → 職員への一次遮蔽・段階表示
- 自由記述中心 → Structured-first
- AI中心 → 原文保存＋フォーム＋Safety＋職員カード＋Export
- 常時LLM → 曖昧・複雑な相談だけAI補助

AIを完全に削除しても目的をよりよく達成できるなら、それを採用する。AIを残すことはSuccess条件ではない。

## 検証順序

```text
Problem Interview
↓
Core Problem Validation
↓
A〜D Pilot
↓
Mental Load + Information Accuracy比較
↓
Practitioner Evaluation
↓
KEEP / REFINE / PIVOT / STOP
```
