# 競合・代替の地形

|カテゴリ/例|主利用者|強み|Kikumaeとの重複|Kikumaeの相対的な弱み|
|---|---|---|---|---|
|デジタル庁モデル仕様/実証|自治体・避難所|名簿、状況報告、通知、地図、物資、本部連携|避難所内の情報収集|制度・連携・調達適合性が未検証|
|バカン避難者マネジメント|自治体・避難所|入所受付、名簿、広域ダッシュボード、既存導入|避難所運営情報|相談整理が差別化になるか未証明|
|紙＋巡回＋班長|現場全員|通信不要、説明不要、対話を維持|ニーズ受付|集計・引継ぎ・検索は弱い可能性|
|Forms/LINE|住民・職員|既存利用、低コスト、導入容易|入力・通知|オフライン、匿名性、業務状態管理は設計次第|
|自治体防災DX/被災者支援基盤|自治体・本部|調達、名簿、生活再建、データ連携|構造化・本部共有|単独導入は重く、Kikumaeは連携仕様がない|

デジタル庁は避難所運営システムのモデル仕様書、サービスカタログ、DMPによる調達環境を整備している。[4][5] Kikumaeが勝てるのは、既存基盤を置換することではなく、相談・要望・原文と対応引継ぎの薄い層を、既存システムへ連携可能なデータで補う場合に限られる。価格・契約条件は個別調査が必要で、現時点で断定しない。
