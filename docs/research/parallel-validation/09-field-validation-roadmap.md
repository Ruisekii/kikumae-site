# 現場検証ロードマップ

|段階|目的|人数/準備|成功|停止|
|---|---|---|---|---|
|1 技術安定化|原文/Safety/状態の再現性|開発・運用少人数、オフライン試験|重大データ欠落なし|Safety/原文不整合|
|2 Problem Interview|課題と代替を把握|自治体等8〜15名|反復する具体的困りごと|文章課題が主要でない|
|3 Pilot|評価法を調整|12〜20名、人工ケース|手順・ログ安定|重大誤り|
|4 修正|失敗を修正|設計レビュー|再現性改善|変更が複雑化|
|5 Practitioner Interview|運用適合性|8〜15名|責任者・業務接点が特定|置換先がない|
|6 Practitioner Evaluation|価値測定|12〜24名|正答維持+時間/負担改善|現行より遅い/不信|
|7 小規模訓練|複数経路・停電を検証|1施設、参加者20〜50|紙/口頭と併用可能|通信断で受付停止|
|8 自治体実証|継続運用と費用を検証|自治体1〜2、期間合意|担当・引継ぎ・効果の再現|個人情報/安全/継続性の問題|

各段階で「KEEP / REFINE / MAJOR PIVOT / STOP」を再判定する。実災害で初めて検証しない。
