# Practitioner Evaluation 計画

自治体防災担当、避難所運営経験者、施設管理者、保健師、防災関係者を12〜24名、役割を分けて募集する。既存業務の経験年数・最近の災害経験・デジタル習熟を記録し、学生結果と混ぜない。

各人に実務に近い短時間ケースをA/Bで提示し、正答率を維持した把握時間、対応判断、負担、信頼、原文確認率を測る。追加で半構造化インタビューを行い、カードが実際の引継ぎに使えるか、誰が入力し、紙/口頭をどう取り込むかを確認する。

成功条件は、Safety重大誤りゼロ、重要情報正答率がAを下回らない、把握時間または負担に一貫した改善、職員が既存フローへ置けると説明できること。失敗条件は原文のニュアンス喪失、現行より遅い、入力経路を狭める、AI不信、運用責任者不在。
