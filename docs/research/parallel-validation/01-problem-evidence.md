# 問題の外部エビデンス

## 強い証拠

内閣府の避難所運営資料は、避難者から要望・困りごとを受ける仕組み、女性・子育て・介護中の家庭のニーズ把握、情報管理、相談窓口を運営項目としている。[1][2] つまり「ニーズを拾い、運営へ反映する課題」は実在する。

厚生労働省は、被災自治体職員が被災者でもあり、長時間勤務、膨大な業務、連続的な意思決定、厳しい意見を受ける立場からメンタルヘルス上の問題を抱えやすいと説明している。[3] 職員負担の一般的存在は **Strong**。

## まだ弱い証拠

「住民の怒り・焦りを含む文章を読むこと」が負担の主要因であること、また「構造化カードが原文と同等の正確さで負担を下げる」ことを直接測った公開一次資料は確認できなかった。**Evidence is weak**。これはKikumaeの中心課題を否定する証拠ではないが、ビジネス価値の根拠にはまだ使えない。

## 現場フローの含意

行政資料からは、口頭・巡回・意見箱・相談窓口など複数経路を併用する前提が読み取れる。したがってWeb入力を唯一の入口にすると取りこぼす。Kikumaeは「受付経路を置換」ではなく、既存の巡回・対話・紙から届いた情報も同じ整理・引継ぎ層へ載せられるかを検証すべきである。
