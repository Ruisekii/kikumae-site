# 反証仮説

|仮説|現時点の判定|検証方法|
|---|---|---|
|A 文章を大量に読まず、口頭・巡回中心|未確認|勤務帯別に受付経路と件数を観察|
|B 整理でニュアンスを失う|重大リスク|原文/カードで重要事実・不確実性・感情の正答率を比較|
|C 人手・物資・引継ぎが本当のボトルネック|十分あり得る|業務時間配分と未処理理由を聞く|
|D デジタル化で距離が遠くなり不満増|未確認|住民・職員双方の不満解決率と対話要求を測る|
|E 高齢者・障害者が使えない|高リスク|支援付き/非デジタル経路の到達率を比較|
|F AI不要、選択肢+ルールで十分|有力|AIなしカード、ルールのみ、LLM整理を三条件比較|

最初から「AIの価値」を測らず、単純なカテゴリ・ルール・紙との比較を必須にする。どの仮説も現状ではUnsupportedまたはEvidence is weakである。
