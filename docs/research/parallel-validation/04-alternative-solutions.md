# 代替手段比較

|手段|導入/住民負担|災害耐性|職員負担|多言語|評価|
|---|---|---|---|---|---|
|紙＋担当者|低/高|高|記録・引継ぎが重い|通訳次第|最低限の対照条件|
|単純カテゴリボタン|低/低|中|集計しやすい|辞書で可能|AIなしの有力候補|
|Forms＋ルール|低/中|通信依存|中|辞書で可能|Kikumaeの最小比較対象|
|LINE|低/低|通信依存|通知は容易|翻訳別途|既存導線の強さがある|
|汎用生成AI|低/中|外部通信/規約依存|要監督|比較的強い|Safety・原文保証が弱い|
|既存自治体基盤|高/中|製品依存|業務連携が強い|製品依存|置換せず連携を検討|
|Kikumae|未確定/低〜中|現状は通信・構成依存|整理で下がる仮説|翻訳層あり|AI上乗せの必要性を実証要|

結論：Kikumaeは「AIだから」では勝てない。単純カテゴリ＋ルール＋原文保持が同等なら、AIは削るべきである。勝ち筋は、複数経路の相談を、失われない根拠付きカードと担当・状態へ変換し、引継ぎ時間を下げること。
