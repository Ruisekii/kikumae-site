# きくまえ — ChatGPT Sites版

「聞きにくいを、聞きやすく。答える手間も、もっと軽く。」を目指し、AIがFAQ検索・質問整理・回答案作成を支援する匿名質問サービスです。

## 体験の流れ

1. 質問者がまずFAQを検索します。
2. 見つからなければ、ログインなしで自然な文章を入力します。
3. AIが類似FAQ、回答者向け要約、カテゴリ候補を作ります。質問の原文は必ず残ります。
4. 質問受付時にAIが回答案を複数用意し、回答者は承認済みFAQを根拠に選択・編集します。
5. 回答者が修正・承認して初めて回答が確定します。
6. 回答後、AIがFAQ候補を作ります。回答者が修正・承認した候補だけが公式FAQになります。

AIは回答やFAQを自動確定・自動公開しません。

## AIとプライバシー

- 質問者はChatGPTへのログイン不要です。回答者画面だけがChatGPT認証とオーナー権限を要求します。
- Sites版の補助AIはWorker内の決定的なローカルモデルです。質問本文を外部AI、解析サービス、トラッカーへ送信しません。
- 将来のOllama等への差し替えを想定し、要約・回答案・FAQ候補を `db/local-ai.ts` の責務境界に分離しています。Ollamaを使うローカル版でも、原文の保持と人の承認ルールを変えません。
- 氏名・メールアドレス・電話番号・住所・URL・学籍番号らしき文字列は受付時に拒否します。
- 質問本文・回答・FAQ候補はFAQ改善のため基本的に継続保存します。不要になった記録は回答者が管理画面から個別削除できます。連絡先は収集しません。
- 公開リポジトリにはD1データ、ログ、鍵、環境変数を含めません。

## 回答者の初回設定

1. 匿名質問を受け付けるため、Sitesの公開アクセスを有効にします。
2. オーナーのChatGPTアカウントで `/staff` を開き、回答者権限を初期化します。管理操作はオーナーIDの秘密環境変数でも固定されます。
3. 公開アクセスでも `/staff` と管理APIはChatGPT認証・オーナー権限がなければ利用できません。

## 開発

```bash
npm install
npm run dev
npm run lint
npm run build
```

D1のテーブルは初回リクエスト時に作成・旧スキーマから加算移行されます。実データをリポジトリへコピーしないでください。
