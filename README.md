# きくまえ — ChatGPT Sites版

「聞きにくいを、聞きやすく。」を目的にした、FAQ検索と匿名質問窓口です。元アプリの公開機能を、ChatGPT Sitesで安全に使える最小構成へ移行しています。

## プライバシーと安全性

- 質問送信はChatGPTへのログインが必要ですが、氏名・メールアドレス・連絡先は保存しません。
- 質問本文は500文字まで、14日後に自動削除します。URL・メールアドレス・電話番号・住所らしき文字列・番号は受け付けません。
- 外部AI・外部解析・トラッカーは使用しません。質問を自動で公開・回答することもありません。
- 回答者用の一覧は、初回にこのSiteのオーナーが `/staff` を開いたときだけ紐付けられます。公開範囲を変更する前に、必ずオーナーが先に設定してください。
- 入力サイズ制限、同一オリジン確認、ChatGPT認証、権限確認、クリックジャッキング・MIME推測対策のHTTPヘッダーを実装しています。

## 公開前の手順

1. Sitesのアクセスをオーナー限定のままデプロイします。
2. オーナーのChatGPTアカウントで `/staff` を開き、回答者権限を初期化します。
3. 必要な場合のみ、Sitesのアクセス設定で閲覧者を追加します。

質問への回答を運用する場合は、個人情報を含む質問を受け取らないよう案内を維持してください。緊急連絡や個別の問い合わせにこの窓口を使わない運用を推奨します。

## 開発

```bash
npm install
npm run dev
npm run lint
npm run build
```

`npm audit` で依存関係を確認してから公開してください。D1のテーブルとFAQ初期データは、初回リクエスト時に自動作成されます。
