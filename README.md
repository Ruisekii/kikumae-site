# きくまえ — ChatGPT Sites版

「聞きにくいを、聞きやすく。答える手間も、もっと軽く。」を目指し、AIがFAQ検索・質問整理・回答案作成を支援する匿名質問サービスです。

## 体験の流れ

1. 質問者がまずFAQを検索します。
2. 見つからなければ、ログインなしで自然な文章を入力します。
3. AIが類似FAQ、管理者向け要約、カテゴリ候補を作ります。質問の原文は必ず残ります。
4. 質問受付時にAIが回答案を複数用意し、管理者は承認済みFAQを根拠に選択・編集します。
5. 管理者が修正・承認して初めて回答が確定します。
6. 回答後、AIがFAQ候補を作ります。管理者が修正・承認した候補だけが公式FAQになります。

AIは回答やFAQを自動確定・自動公開しません。

## AIとプライバシー

- 質問者はChatGPTへのログイン不要です。管理画面だけがChatGPT認証とオーナー権限を要求します。
- Sites版の補助AIはWorker内の決定的なローカルモデルです。質問本文を外部AI、解析サービス、トラッカーへ送信しません。
- 将来のOllama等への差し替えを想定し、要約・回答案・FAQ候補を `db/local-ai.ts` の責務境界に分離しています。Ollamaを使うローカル版でも、原文の保持と人の承認ルールを変えません。
- メールアドレス・電話番号・住所・URL・学籍番号など、検出できる個人情報らしき文字列は受付時に拒否します。これは簡易パターン検出であり、氏名など自然文の個人情報を完全に判定するものではないため、入力時にも個人情報を書かないよう案内します。
- 質問本文・回答・FAQ候補はFAQ改善のため基本的に継続保存します。不要になった記録は管理者が管理画面から個別削除できます。連絡先は収集しません。
- 公開リポジトリにはD1データ、ログ、鍵、環境変数を含めません。

## 管理者・運営者の初回設定

1. 匿名質問を受け付けるため、Sitesの公開アクセスを有効にします。
2. オーナーのChatGPTアカウントで `/admin` を開き、管理権限を初期化します。管理操作はオーナーIDの秘密環境変数でも固定されます。
3. 公開アクセスでも `/admin`（旧 `/staff` はリダイレクト）と管理APIはChatGPT認証・オーナー権限がなければ利用できません。

各窓口の管理者は、窓口作成時のパスワードで `/:slug/admin` に入り、自分の窓口だけを管理・削除できます。きくまえ全体の運営者画面 `/owner` は、`KIKUMAE_OWNER_USER_ID` と一致するChatGPTアカウントだけが利用できます。

## 開発

```bash
npm install
npm run dev
npm run lint
npm run build
```

D1のテーブルは初回リクエスト時に作成・旧スキーマから加算移行されます。実データをリポジトリへコピーしないでください。
